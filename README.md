# Organization community files

The public organization profile is [profile/README.md](profile/README.md), with Portuguese and Spanish translations. This repository provides default community files for projects that do not define their own.

Before publishing, follow [SETUP.md](SETUP.md). Original documentation and templates here are MIT licensed; the [Code of Conduct](CODE_OF_CONDUCT.md) is Contributor Covenant 2.1, CC-BY-4.0, as attributed there.

The organization already exists as [revive360](https://github.com/revive360). Read [review levels](REVIEW.md), [governance](GOVERNANCE.md), [CI capacity](CI.md) and the [required app README notices](APP_README_TEMPLATE.md). The local catalog examples are demonstrations, not active certifications. Workflows are not inherited as community defaults: copy/configure checks in each receiving repository.
