# Revive360: the house files

This is where the crew keeps the rules, contribution guides and issue templates. The public face is [profile/README.md](profile/README.md), with [português](profile/README.pt-BR.md) and [español](profile/README.es.md) alongside it. Pick your language. Bring work you can explain.

Start a conversation in [Discussions](https://github.com/orgs/revive360/discussions). Got a concrete fix or app ready for review? Read [CONTRIBUTING](CONTRIBUTING.md) and use the matching form. The eleven [house rules](profile/README.md#rules) apply across the org.

The organization already exists as [revive360](https://github.com/revive360). Before putting these files online, work through [SETUP.md](SETUP.md). Workflows and settings must be configured in each repo; community-file inheritance does not configure them.

The formal references stay precise: [governance](GOVERNANCE.md), [review levels](REVIEW.md), [security](SECURITY.md), [CI capacity](CI.md) and the [required app notices](APP_README_TEMPLATE.md). Catalog examples remain demonstrations, not active certifications.
