[Official org setup](https://docs.github.com/en/organizations/managing-organization-settings/enabling-or-disabling-github-discussions-for-an-organization), [repo setup](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/enabling-features-for-your-repository/enabling-or-disabling-github-discussions-for-a-repository).
3. In **`.github` → Discussions → Categories → pencil icon**, edit the existing matching category or choose **New category**. Set title, description and format, then **Create** / **Save changes**:

| Category title | Format | Purpose |
| --- | --- | --- |
| **Announcements / Anúncios** | Announcement | Official news; creation restricted to maintainers/admins by the format. |
| **App ideas / Ideias de apps** | Open-ended discussion | Explore app ideas before a formal catalog/admission request. |
| **Help / Ajuda** | Question and answer | Community support, with accepted answers. |
| **Show and tell / Mostre seu projeto** | Open-ended discussion | Demos and projects; posting is not a badge or admission. |

Keep existing conversation history when renaming defaults. [Official category instructions](https://docs.github.com/en/discussions/managing-discussions-for-your-community/managing-categories-for-discussions).
